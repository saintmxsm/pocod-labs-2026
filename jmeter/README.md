# Тест-планы Apache JMeter

Запускать из этой папки в Apache JMeter 5.6.3 или совместимой версии.
lab3.jmx: главная страница один раз, затем три случайных перехода.
lab4.jmx: главная страница один раз, затем восемь строк services.csv.
Один поток, паузы, тайм-аут подключения 10 секунд и ответа 15 секунд.
Response Assertion в lab4 проверяет буквальное наличие слова «Яндекс».
Ошибки этой проверки на редиректах, защитных страницах или страницах с иным брендингом не скрываются.
Запись запросов и результаты выполнения находятся в локальных материалах отчётов.
