# Рабочий процесс Git

1. Проверить состояние: `git status`.
2. Создать ветку: `git checkout -b feature-name`.
3. Внести изменения и проверить `git diff`.
4. Добавить файлы: `git add`.
5. Создать коммит: `git commit`.
6. Отправить ветку: `git push -u origin feature-name`.
7. Перейти на main и объединить ветки командой `git merge --no-ff`.
8. Отправить обновлённую main и проверить историю.
